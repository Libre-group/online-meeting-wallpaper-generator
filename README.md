# オンライン会議用 背景画像ジェネレーター

Google Meet / Zoom / Microsoft Teams などの Web 会議ツールで使う背景画像を、
会社名・ロゴ・氏名・キャッチコピーを入力するだけで生成するブラウザ完結型ツールです。

- 仕様書: [docs/SPEC.md](docs/SPEC.md)
- ステータス: 要件定義中（ヒアリング事項は仕様書 §12 を参照）

## 方針

- インストール不要・アカウント不要（単一 HTML ファイル）
- 入力した画像・テキストは外部に送信せず、ブラウザ内だけで処理
- 会議画面で「切れない・隠れない・読める」配置をデフォルトで担保
