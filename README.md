# オンライン会議用 背景画像ジェネレーター

Google Meet / Zoom / Microsoft Teams などで使う背景画像を、会社名・ロゴ・氏名・
キャッチコピー・QRコードを入力するだけで生成するツールです。

## 使い方

`index.html` をブラウザで開くだけです。インストールもアカウント登録も不要で、
社内配布は共有ドライブに置くか、メールに添付するだけで済みます。

1. 背景画像・ロゴ・マスコット画像（いずれも任意）を選ぶ
2. 会社名・氏名・肩書などを入力する（会社名は改行で最大4行。グループ名と所属法人の併記に使えます）
3. レイアウト A〜E から選ぶ
4. 「背景画像をダウンロード」を押す

## 特長

- **入力した画像・文字は一切外部に送信しません。** すべてブラウザ内で処理します
  （`fetch` / `XMLHttpRequest` を使用せず、CDN からの読み込みもありません）。
- **会議画面で切れない・隠れない配置。** 会議ツールは参加者タイルの形に合わせて
  背景の左右を切り落とします。正方形タイルでは左右 21.9% が必ず失われるため、
  既定ではその内側に文字を配置します。プレビューで 16:9 / 4:3 / 1:1 の
  見え方を同時に確認できます。
- **開いた時点で会社の設定が入っている。** 管理者が設定を済ませて
  「この設定を既定にしたHTMLを書き出す」を押すと、その設定を埋め込んだ `index.html`
  が得られます。共有先のファイルを置き換えれば、各自は開いて氏名を入れるだけです。
  テンプレートの編集機能はそのまま残ります（「テンプレート編集」モード）。
  背景画像・ロゴ・マスコットは常に埋め込まれ、氏名・肩書・連絡先などの個人情報は
  含まれません。
- **文字もロゴもマスコットも、9か所から置き場所を選べる。** 基準点ごと切り替わるので、
  「下」を選べば下端に揃い、はみ出しません。そこからドラッグで微調整できます。
- **色を自由に決められる。** 背景に重ねる色、文字の下のパネル・帯の色をそれぞれ指定でき、
  ダーク／ライト／ブランド色のプリセットもあります。
- **マスコット画像を置ける。** ロゴとは別に、キャラクター画像を四隅のいずれかに
  配置できます。大きさ・左右反転・位置の微調整に対応しています。
- **縦横比の違う画像を入れても全体が入る。** 16:9 でない画像を読み込むと、
  切り取られる割合を知らせたうえで「画像全体を入れる」に自動で切り替え、
  余白は同じ画像のぼかしで埋めます。
- **QRコードも外部通信なしで生成。** 自前実装のエンコーダーを同梱しています。

## 社内で配る手順（管理者の方へ）

1. `index.html` を開き、「テンプレート編集」モードで背景・ロゴ・会社名・配色・
   レイアウトを決める
2. 「この設定を既定にしたHTMLを書き出す」を押す（背景画像も含めたい場合は
   その下のチェックを入れる）
3. 書き出された `index.html` を、共有ドライブや社内サーバーの元のファイルと置き換える
4. 各自は開いて氏名などを入れ、「背景画像をダウンロード」を押すだけ

設定を変えたくなったら、2 と 3 を繰り返してください。すでに使っている人の画面でも、
次に開いたときに新しい会社設定へ自動で切り替わります（入力済みの氏名はそのまま残ります）。
